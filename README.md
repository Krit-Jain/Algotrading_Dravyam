📈 Past N Months Gainer based Strategy

A modular, research-driven algorithmic trading framework developed for Dravyam, focused on multi-factor momentum, seasonal patterns, and hybrid signal-generation/backtesting engines on NSE universes (Nifty 750 & FnO).

This repository contains two categories of systems:

STOCKS files → Signal Generators

STRATEGY files → Full Backtesting Engines

Both are driven by the same core logic, based on a hybrid seasonal + momentum approach. The difference lies in the type of gainers selected, the return window, and holding-period mechanics, making Strategy-1 and Strategy-2 distinct models.
